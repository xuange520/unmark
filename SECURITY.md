## Reporting a Vulnerability

We take the security and integrity of `Unmark` seriously.

If you believe you have found a security vulnerability in this project or have concerns regarding statistical watermark robustness and ethical AI evaluations, please report it directly by emailing:

📧 **xuangeylw@gmail.com**

Please include the following details in your report:
- Type of issue / vulnerability.
- Location of the affected source code (file and line numbers).
- Step-by-step instructions or proof-of-concept (PoC) to reproduce the issue.
- Any potential mitigation suggestions.

We will acknowledge receipt of your vulnerability report within 48 hours and work on a prompt resolution.

## Responsible Research & Ethical Disclaimer

`Unmark` is developed for academic research, AI robustness auditing, and responsible evaluation of machine-generated text watermarks. Users are responsible for complying with applicable laws, institutional ethics policies, and academic integrity regulations.
